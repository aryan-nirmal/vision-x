# Vision X — Autonomous Support Teammate for Paytm

> **"A support reply is not the same as a resolution."**  
> Built for the Paytm "Build for India" AI Hackathon (Pune).

Vision X is an autonomous, verifiable AI Teammate for customer support that investigates issues across core banking and Paytm systems, takes safe actions, and verifies state changes before marking tickets done.
